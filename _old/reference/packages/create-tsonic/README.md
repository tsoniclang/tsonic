# `create-tsonic`

Create and install a complete Tsonic project with one command:

```sh
npm create tsonic@latest hello -- --target csharp
```

Use `--target rust` for Rust. The selected target owns the starter source,
configuration, native toolchain requirements, and npm scripts. The creator
validates those requirements and publishes the project directory only after
installation succeeds.

See the [first-project guide](https://github.com/tsoniclang/tsonic/blob/main/docs/manual/get-started.md).
